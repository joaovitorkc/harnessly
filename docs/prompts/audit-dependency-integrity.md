# HLY-010 — Audit dependency and lockfile integrity

Executable: [`../../prompts/audit-dependency-integrity/PROMPT.md`](../../prompts/audit-dependency-integrity/PROMPT.md)
Manifest: [`../../prompts/audit-dependency-integrity/manifest.yaml`](../../prompts/audit-dependency-integrity/manifest.yaml)

## Use it when

A monorepo has multiple lockfiles/managers, CI does unlocked installs,
wrappers float, or dependency advisories need a controlled baseline.

## Default behavior

`NETWORK=DENY`, `VULNERABILITY_SCAN=OFF`, and `UPDATE_POLICY=NONE` produce a
local evidence audit. No restore, install, audit service, lock generation, or
update runs.

## Gated behavior

Lock repair, patch updates, native advisory network calls, wrappers, and
lifecycle scripts require an exact manager-boundary gate. Lockfiles are
generated by their manager, never edited manually.

## Ecosystems

The workflow reasons from npm/pnpm/Yarn/Bun, Python, Go, Cargo, Maven/Gradle,
.NET, and wrapper-specific evidence. A project without managed dependencies is
`N/A`.

## Example

```text
Follow HLY-010 with MODE=ASSESS NETWORK=DENY
VULNERABILITY_SCAN=OFF UPDATE_POLICY=NONE.
```

## Done when

Every unit has one evidenced manager and lock strategy, workspace membership
reconciles, lifecycle scripts are visible, local/CI restore agrees, advisory
coverage is time-bounded, and documentation-only mode leaves dependency files
unchanged.
