# Roadmap

## v0.1 — foundation

- Portable execution contract and risk model.
- Complete one-prompt Standard setup and Advanced Orchestrator routing.
- Eleven discovery, documentation, harness, quality, and security workflows.
- Deterministic schemas, adapters, fixtures, scenarios, and release digests.
- Honest compatibility evidence.

## Candidate v0.2 workflows

- Shape a feature into acceptance criteria and an atomic plan.
- Diagnose a bug from runtime evidence before editing.
- Implement an approved plan with scoped verification.
- Review a diff with independent domain/security lenses.
- Refactor oversized modules without changing behavior.
- Build missing tests from an explicit behavior contract.
- Accessibility, performance-budget, logging, and observability baselines.

## Later, only with evidence

- Optional local CLI for catalog discovery, integrity checking, preview, and
  fixture materialization.
- Signed provenance/attestations.
- More CI providers and operating-system fixtures.
- Community workflow registry and compatibility test submissions.

## Explicitly not planned as defaults

- autonomous deploy or production access;
- automatic Git commits/pushes;
- secret ingestion;
- migration of repositories into orchestrators;
- mandatory hosted service, telemetry, or account.
