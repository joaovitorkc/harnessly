An **Output Artifact** is either:

- a file created specifically inside a user's target repository by executing
  or following a Harnessly workflow; or
- the workflow-generated portion added to or modified within a pre-existing
  file in that target repository.

This exception applies only to the generated portion, not to pre-existing user
or third-party content surrounding it. Output Artifacts may describe,
configure, test, or implement behavior for the target repository.

This additional permission includes generated project-specific `AGENTS.md`,
`CLAUDE.md`, rules, skills, agent profiles, design documents, harness
documents, task templates, verification scripts, and configuration fragments.

It does not include:

- Harnessly's canonical `PROMPT.md` files or human guides;
- a redistributed Harnessly workflow, catalog, schema, rule, skill, agent
  definition, or template;
- substantial verbatim copies of Harnessly source material made for the
  purpose of publishing a competing or derived toolkit;
- third-party material governed by a separate license.

For clarity, the exception covers managed blocks, structural merges,
source/test patches, configuration fragments, and other workflow-generated
portions in the target repository, whether or not the destination file existed
before execution.
